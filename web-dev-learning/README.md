# Web Development Learning Path

This folder is a curated, portfolio-friendly learning path for becoming a web developer.

## Contents
- `roadmap.md` — step-by-step plan from beginner to intermediate/advanced
- `resources.md` — curated articles, tutorials, docs, and projects
- `project-ideas.md` — portfolio project ideas and how to present them
- `portfolio-template.md` — copy-ready portfolio section and project README structure

## Suggested order
1. Learn HTML, CSS, and JavaScript fundamentals
2. Practice responsive layouts and accessibility
3. Build small frontend projects
4. Learn React and modern tooling
5. Add backend basics (Node.js/Express/API)
6. Deploy, test, and polish your portfolio

## Focus areas
- Frontend: HTML, CSS, JavaScript, React, responsive design
- Backend: APIs, databases, auth, deployment
- Professional skills: Git, debugging, testing, CI/CD, accessibility

## Goal
Build a small portfolio of 3–5 strong projects that showcase your growth and technical skills.
