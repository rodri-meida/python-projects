# Web Development Resources

A short list of the best resources to learn web development efficiently.

## Core references

### HTML, CSS, JavaScript
- MDN Web Docs — https://developer.mozilla.org/
- JavaScript.info — https://javascript.info/
- CSS-Tricks — https://css-tricks.com/

### React
- React Docs — https://react.dev/
- Vite Docs — https://vitejs.dev/

### Backend
- Node.js Docs — https://nodejs.org/en/docs/
- Express Docs — https://expressjs.com/
- PostgreSQL Docs — https://www.postgresql.org/docs/

### Practice and challenge sites
- Frontend Mentor — https://www.frontendmentor.io/
- freeCodeCamp — https://www.freecodecamp.org/
- The Odin Project — https://www.theodinproject.com/

### Accessibility and UX
- W3C Accessibility — https://www.w3.org/WAI/
- A11Y Project — https://www.a11yproject.com/

### Deployment
- Vercel Docs — https://vercel.com/docs
- Netlify Docs — https://docs.netlify.com/
- Render Docs — https://render.com/docs

## Recommended study order
1. HTML + CSS basics
2. JavaScript fundamentals
3. DOM and events
4. Responsive design
5. React
6. APIs and backend basics
7. Testing, deployment, and accessibility

## Learning tip
Use tutorials to understand concepts, then rebuild small features from memory without copying the code.
