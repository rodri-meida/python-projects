# Web Development Roadmap

This roadmap helps you learn web development in a structured way while keeping your portfolio visible and relevant.

## Phase 1 — Fundamentals (Weeks 1–2)

### HTML
- Semantic structure (`header`, `main`, `section`, `footer`)
- Forms and input validation
- Accessibility basics
- Images, links, tables, and media

### CSS
- Box model, positioning, flexbox, grid
- Responsive design using media queries
- Variables, pseudo-classes, transitions
- Typography and spacing systems

### JavaScript
- Variables, functions, arrays, objects
- DOM manipulation
- Events and forms
- `fetch()` for APIs
- Modern ES6+ syntax

### Suggested resources
- MDN Web Docs
- JavaScript.info
- CSS-Tricks

## Phase 2 — Frontend Practice (Weeks 3–5)

Build small projects after each concept:
- landing page
- product card
- pricing section
- blog homepage
- to-do list
- weather app

Key topics:
- Responsive UI patterns
- State handling
- Async JavaScript
- Error handling
- Local storage

## Phase 3 — Frameworks and Modern Workflow (Weeks 6–8)

### React
- Components and props
- State and events
- Hooks (`useState`, `useEffect`, `useMemo`)
- Conditional rendering
- Component structure

### Tooling
- npm / package management
- Vite or bundler basics
- Environment variables
- CSS frameworks like Tailwind or SCSS

### Practice projects
- dashboard UI
- notes app
- movie search app
- recipes app

## Phase 4 — Backend Basics (Weeks 9–11)

Learn the fundamentals of web apps beyond frontend:
- Node.js basics
- Express.js
- REST APIs
- Database basics (PostgreSQL or MongoDB)
- Authentication concepts
- Environment variables and security

### Practice
- API for a task manager
- blog backend
- user auth flow with JWT or session-based auth

## Phase 5 — Deployment, Testing, and Polish (Weeks 12–14)

- GitHub version control
- GitHub Actions
- Testing with Jest / React Testing Library / Playwright
- Lighthouse and accessibility audits
- Deployment to Vercel / Netlify / Render
- Environment configuration and production best practices

## Portfolio Milestones

### Milestone 1
- 2 simple HTML/CSS/JS projects

### Milestone 2
- 1 React project

### Milestone 3
- 1 full-stack project or API-driven app

### Milestone 4
- polished portfolio and case studies

## Weekly habit
- 4–6 hours per week minimum
- Build one small project every 1–2 weeks
- Write a short note about what you learned
- Improve one project each week

## Good learning rule
Do not stay too long in tutorials. Build, break, fix, and explain your own code.
